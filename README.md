# Spotify SQL Optimization Project

This project focuses on converting a denormalized Spotify dataset into a normalized relational database schema and executing complex SQL queries to analyze artist trends and track popularity. Optimization techniques such as indexing and execution plan tuning were used to enhance performance and efficiency.

## Features
- Normalized Spotify schema
- Complex SQL queries for artist and track analysis
- Performance optimization using indexes and execution plan analysis

## Folder Structure
- `schema_design/`: SQL schema and ERD for the normalized database
- `queries/`: SQL scripts for data analysis and optimization
- `performance/execution_plans/`: Screenshots or outputs of execution plans

## Tech Stack
- MySQL

## Getting Started
1. Import the schema from `schema_design/normalized_schema.sql` into your MySQL database.
2. Run queries in the `queries/` folder to analyze data.
3. Analyze execution plans for optimization.
